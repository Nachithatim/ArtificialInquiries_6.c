# Artificial Inquiries – Exercice 6.c

## What's on the Line?

### Description de l'exercice

L'exercice 6.c consiste à analyser quatre tâches professionnelles sélectionnées pour tester un LLM.

Pour chaque tâche, l'objectif est de réfléchir à son importance dans notre pratique professionnelle et de définir les critères qui permettront d'évaluer la réponse du LLM.

Chaque tâche contient les informations suivantes :

- Task ID
- Task Fit
- Professional Relevance
- Personal Outcome
- Expected Performance
- Confidence
- Good Enough
- Failure
- Success

L'objectif est de déterminer ce qu'on attend du LLM avant de réaliser le test et d'identifier ce qui représente un résultat acceptable, un échec ou un résultat idéal.

## Solution technique

Pour gérer les données de l'exercice, chaque tâche sera représentée comme une entité contenant ses informations et ses critères d'évaluation.

Les données pourront être organisées dans Omeka S afin de conserver les différentes tâches et leurs évaluations.

Un diagramme de classes réalisé avec Mermaid permettra de représenter la structure des données et les relations entre les éléments de l'exercice.

## Technologies utilisées

- GitHub : stockage et versionnement du projet
- Markdown : documentation
- Mermaid : diagramme de classes
- Omeka S : gestion des données
- Apache, PHP et MySQL : environnement local pour Omeka SS
